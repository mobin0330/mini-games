# 甜品消消乐

甜品主题的 8 × 8 不限时消消乐。纯前端实现，无构建步骤；使用自制 SVG 甜品素材、Kenney CC0 音效与 CC0 循环背景音乐。

## 运行

直接用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```sh
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。游戏在 `game/app.py` 中按显式白名单提供资源，`assets/`、`audio/` 目录不会整体暴露。

## 玩法

- 点击或滑动交换相邻甜品，横向或纵向连成三个及以上同色甜品即可消除。
- 交换、消除、下落与连锁都有分段节奏：先逐格破碎、再按列下落，连锁之间留出短暂的呼吸拍。基础消除从点击到可再次操作约 0.5 秒。
- 不限时间、不限步数。一次交换引发的连续消除会形成连锁 Combo，倍率与反馈逐层增强。
- 特殊甜品：
  - 四连生成 **火箭糖**，清除整行或整列；方向与连成的方向一致。
  - T / L 型消除生成 **巧克力炸弹**，清除周围 3 × 3。
  - 五连生成 **彩虹棒棒糖**，与任意甜品交换时清除全场同色甜品。
  - 特殊甜品被卷入消除时会连锁触发。
- 无效交换会恢复原状且不消耗步数；没有可行组合时会自动重排并保留分数与步数。
- “提示一步”会高亮一组可以交换的甜品，不消耗步数。
- 键盘：方向键移动焦点，Enter / 空格选择，Esc 取消选择。触屏可按住拖动交换。
- 音效与循环背景音乐默认开启，可一键关闭，状态保存在 `match3.sound` / `match3.haptics`。
- 最高分保存在 `match3.best`；存储不可用时自动降级，不影响游戏。

## 文件

- `index.html`：页面结构、HUD、状态区、特殊玩法说明、环境装饰层、声音/震动开关。
- `styles.css`：甜品柜台视觉、放大后的甜品素材、环境漂浮与棋盘扫光、逐格破碎/按列下落、Combo/新纪录/飘分、响应式布局与减少动态效果支持。
- `app.js`：增量渲染、交换与连锁节奏、Combo、飘分、碎片/冲击环/闪光、屏幕震动、输入与持久化。
- `engine.js`：纯逻辑 Match-3 引擎，含特殊糖生成、连锁触发与计分。
- `sfx.js`：基于 Web Audio 的 MP3 预加载、音效播放、循环 BGM、压缩器与总音量控制。
- `assets/`：六种甜品与两种特殊效果 SVG（自制，已按内容边界裁切 viewBox）。
- `audio/`：12 个 MP3 音效与 1 首循环背景音乐，来源与许可证见 `audio/CREDITS.md`。
- `tests/engine.test.cjs`、`tests/ui.test.cjs`：引擎与界面行为测试。
- `acceptance/engine.contract.cjs`：只读验收契约。

## 测试

无需安装依赖：

```sh
node --test acceptance/engine.contract.cjs tests/engine.test.cjs tests/ui.test.cjs
```

界面测试使用 Node 内置 `vm` 与轻量 DOM/计时器/存储测试夹具执行真实的 `app.js` 绑定，覆盖选择、无效与有效交换、连锁 Combo、特殊糖出现时机、音效/震动开关、提示、重开、键盘导航和存储失败。
