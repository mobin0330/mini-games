# 素材与许可

本作美术使用本任务中的 imagegen 生成，并已复制到工程内。原始输出仍保留于生成工具的目录；项目不依赖该外部路径。没有挪用参考游戏截图作游戏贴图。

| 文件 | 用途 |
|---|---|
| atlas-clean.png | 主角基础动作、两类敌人、货箱、气闸，透明图集 |
| run-cycle.png | 主角八帧连续跑步 |
| animations.png | 四帧挥刀、落地、冲刺、受伤、搬运 |
| environment.png | 平台、墙板、压力踏板、动量接收器、引力发生器、危险装置、锚点、核心 |
| backdrop.png | 第一章冷白测试设施 |
| shaft.png | 第二章能量深井 |
| workshop.png | 第三章工业装配车间 |
| core.png | 第四章警戒中枢 |
| fonts/NotoSansSC.ttf | Google Fonts / Noto Sans SC 可变字体，SIL Open Font License；许可同目录 OFL.txt |
| ui/*.svg | 原创程序绘制的简单开关/滑块控件符号，非游戏模型替代品 |

美术方向：严格2D正交侧视、深蓝工业金属、磨损暖白陶瓷、青色面罩与橙色引力核心，要求实际可用图集与透明留白。初版图集带白色半透明底，已重新生成透明修正版；正式渲染只使用 atlas-clean.png。图集只裁定显示边界，不重绘或涂改角色。能量门、箭头、导线和粒子使用清晰几何特效，实体使用生成素材。

音乐及音效由代码合成，不包含外部音乐、配音或商业采样。当前不是录制的完整原声专辑。
