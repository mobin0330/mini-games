# 关卡设计与可验证解法

所有关卡均是一个完整谜题房，入场为检查点。R 或死亡恢复该房的初始角色、方块、机关与传送门，保留已解锁章节。角色重试迅速，不回退整章。所有必要条件参与出口判定；不能只走到气闸跳关。

| 关卡 | 教学、可见空间与新规则 | 已验证正常解法 | 组合、恢复与约束 |
|---|---|---|---|
| 1-1 第一块地面 | 两级维修台、右侧紫色引力舱；移动、跳跃、冲刺 | 跳过维修台，进入右引力场，沿竖墙向上行动，越过隔板到右侧气闸 | 必须经过侧向锚点；此房没有致命陷阱，R 可复位 |
| 1-2 墙也是地面 | 三个发光锚点、交错上下隔墙；解锁主动重写 | 向上重力到天顶锚点，在天花板向右行走，向下切换穿过侧壁锚点，回地面向右到出口 | 世界动量保留、四向着地与跳跃；三个锚点均需访问 |
| 2-1 深井飞行 | 高起点、井底蓝门、右向橙门、右壁动量接收器；解锁双门 | 走下起点平台，反向输入制动对准井底门；坠落后从墙面射出撞亮接收器，再走入气闸 | 首次门位已设好便于观察，之后可自行重放；接收器需650 px/s且至少穿门一次。实测输入路线出门约858 px/s |
| 2-2 水平不代表停止 | 地面青绿限时接收器与出口前隔墙 | 在天花板对准接收器，重力向下高速撞击；8秒内重力向上越过隔墙，天花板制动对准出口，再向下进入 | 只触发不穿过无效；倒计时到零重新锁定。过早切换方向仍会保留切向速度，需主动制动 |
| 3-1 重量与方向 | 两个货箱、地面压力踏板、右壁引力舱 | F 拾取第一箱压踏板；第二箱带进右引力场，沿墙移动到方向触点，释放后货箱向右压住接收器；向上离场到气闸 | A/B均锁存，完成后可搬走箱子；方向机关只收独立货箱的有效向右压力 |
| 3-2 三重协奏 | 三箱、中央墙、三种接收器及可见AND线路 | 第一箱锁存重量；在中央墙右面设橙门，把箱子带到天花板，切为向下、井底放蓝门并释放，让落差变水平撞击；第二箱进入右侧场压方向触点 | 三个条件逐个锁存，无需持续占据三个点。可重复使用同一货箱；重量→动量→方向是记录路线，重量→方向→动量也是合法次序。X收门可避免回程意外循环 |
| 4-1 另一种士兵 | 巡逻守卫、盾卫、货箱、上方危险场 | 搬箱接近守卫，冲刺中释放，高速箱击杀；取回箱子再向盾卫投送，最后到气闸 | 自动路线实际验证零次挥刀完成。另可近战背击/引入上方重力场；前盾拒绝正面普通近战。敌人不会自动走进地面陷阱 |
| 4-2 零向中枢 | 中枢锚点、三个正交动量锁、机械核心 | 先访问天顶锚点；第一箱坠入蓝门，经右向橙门撞第一锁；新上引力场出现后携第二箱向上加速并释放撞天顶锁；场消失后从天顶向下释放撞地面锁 | 防护必须I→II→III。完成后去左或右终端，靠近按F选择。不会因为经过终端而自动选结局；所有锁需要独立货箱高速冲击 |

完整路线脚本 `tests/playthrough.gd` 使用正常物理时间步、移动/跳跃/冲刺输入及玩家公开操作接口，不直接设置角色位置或写入完成标志。`--late`/`--final` 仅跳过已验证前段；正常无参数执行全部八关。另一个测试文件 `run_tests.gd` 刻意用布置状态检查物理边界，二者证据不能混为一谈。

首次游玩需要自行观察与尝试，本次没有真人首通时长数据。不要将已知解法的自动路线时长当作25—45分钟的真人体验证明。
