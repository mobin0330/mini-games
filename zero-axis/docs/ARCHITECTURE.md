# 工程架构

- `physics_rules.gd`：统一重力优先级、切线、速度矩阵、跨帧穿门、定向冲量和AND/OR规则。
- `actor.gd`：共享 CharacterBody2D 运动控制，玩家、箱子、巡逻兵、盾卫使用同一重力/传送入口。圆碰撞体避免重力旋转时穿墙。世界速度和局部控制轴分离；up_direction同步有效重力。
- `game.gd`：房间生命周期、实体集合、门放置射线、出口安全检测、机关、拾取释放、伤害与最终选择。传送后清空拖尾并 reset_physics_interpolation，禁止跨屏插值。
- `levels.gd`：八关数据、初始位置、几何碰撞、引力场优先级、接收器、目标和日志。固定120 Hz；最大速度1800 px/s。
- `room_view.gd`：正交场景绘制，工业素材拼接、引力箭头、门能量轮廓、机关连线、粒子。
- `art.gd` / `atlas_regions.gd`：贴图加载、预烘焙图集边界，启动时不逐像素扫描图集。透明PNG原文件不修改。
- `ui.gd`：CanvasLayer 固定HUD、圆盘、菜单、设置、键位冲突检查和章节选择。
- `save_store.gd`：原子临时文件写入再重命名，本地JSON存档；最近关卡不能超出解锁范围。
- `audio.gd`：本地程序生成氛围循环与事件音效，无外部网络依赖。

## 数值约定

门切线统一为 `(normal.y, -normal.x)`；速度使用 `-dot(v,t_in)*t_out - dot(v,n_in)*n_out`。所有16组正交方向组合检验速度守恒与可逆性；无额外力时误差小于0.001 px/s。穿门用本步轨迹与实体半径检测，而非依赖 Area2D 进入信号。出门保留切向偏移，检查墙体和实体空间，携带货箱也必须有合法出口。

压力踏板允许多个实体；方向触点要求箱子接触且重力朝向受压面；动量机关检查接近速度的法线分量。计时触点8秒，其他关卡明确采用锁存。关闭气闸只撤销关卡完成权限，不生成会夹住实体的动态碰撞体。

## Web 与安全边界

游戏没有自己的账户、认证客户端或认证接口。`game/app.py` 复用 `shared_email_auth` 1.2.2 与 `EmailHTTPMixin`。所有 `/zero-axis/` 构建资源受统一会话校验和显式文件白名单保护。

SDK 1.2.2 新增 `wasm_prefixes`，必须属于已保护目录；仅为匹配路径增加 `wasm-unsafe-eval`，不允许 JS eval/inline，不改变来源/HTTPS/Cookie验证。HTTP 与 ASGI 的业务响应支持同一规则，其他消费者保留旧策略。AgentFlow 的版本锁同步升级并回归。没有新建认证凭据。
