# 五子棋（本地双人对战）

纯前端、无依赖、无需构建的 15×15 五子棋。黑棋先行，双方轮流落子，横、竖、斜任意方向连续五子或更多即获胜；支持悔棋、重新开始、胜负/和棋提示、最后一手标记与获胜连线高亮。

## 启动

直接双击 `index.html` 即可在浏览器中开始游戏（`file://` 可运行）。

也可以在项目目录启动一个本地静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 操作

- 鼠标或触屏点击棋盘交叉点落子。
- 键盘：`Tab` 在棋盘格与按钮间移动焦点，`Enter` 或空格在聚焦的格子上落子。
- `悔棋`：撤销上一手，终局后也可悔棋并继续对局。
- `重新开始`：清空棋盘，回到黑棋先行。

状态区域使用 `aria-live`，会播报当前回合、获胜方或和棋结果。

## 测试

使用 Node.js 内置测试运行器，无需安装依赖：

```sh
node --test tests/engine.test.cjs tests/ui.test.cjs
```

`tests/ui.test.cjs` 在 Node VM 中加载真实的 `app.js`，用最小 DOM 假对象驱动界面，覆盖初始棋盘、落子轮转、占用格保护、悔棋、重开、键盘落子、终局高亮与禁用、和棋反馈等行为。
