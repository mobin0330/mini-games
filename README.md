# 小游戏合集

| 游戏 | 玩法 |
| --- | --- |
| [五子棋](gomoku/) | 15×15 棋盘，本地双人对战，支持悔棋和重开 |
| [贪吃蛇](snake/) | 经典贪吃蛇，支持键盘和触屏 |
| [甜品消消乐](match3/) | 8×8 棋盘，支持连锁计分、特殊糖果和本地最高分 |
| [重力风暴：零向协议](zero-axis/) | Godot 2D 重力解谜，四章八关、双结局 |

在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后在浏览器访问 `http://127.0.0.1:8000/gomoku/`、`/snake/` 或 `/match3/`。

在 Godot 4.5.2 中导入 `zero-axis/project.godot`，按 F5 运行项目。桌面和 Web 构建可按该游戏 README 中的步骤自行导出。
